# Branding de OpenConex

Propuesta final: **azul AISC**, construida a partir de la estructura de conexiones de acero.

## Archivos

| Archivo | Uso |
|---|---|
| `aisc/banner-github.png` | Banner del README · 1600 × 600 |
| `aisc/github-social-preview.png` | Social preview del repositorio · 1280 × 640 |
| `aisc/splash.png` | Splash de referencia · 1000 × 700 |
| `aisc/icon.ico` | Icono de Windows |
| `aisc/icon.svg` | Icono vectorial |
| `aisc/icon-*.png` | Exportaciones de 16 a 1024 px |
| `aisc/render-blue.png` | Render recortado y coloreado |
| `aisc/preview.html` | Vista previa completa |
| `aisc/README.md` | Concepto, paleta y guía de uso |

## Integración

- El banner se muestra al inicio del `README.md`.
- Los iconos de la aplicación se copian a `src/openconex/data/branding/`.
- El splash de la aplicación se genera sin versión fija; la versión se dibuja en tiempo de ejecución.
- El social preview se configura manualmente en **Settings → Social preview** del repositorio.

## Estado

Assets visuales integrados en la aplicación y en la página del repositorio. La publicación de una nueva versión portable se realiza por separado.
