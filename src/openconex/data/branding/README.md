# Branding assets

Assets used by the desktop application at runtime.

- `splash.png`: splash screen, without a fixed version number. The GUI draws `v{__version__}` on top.
- `icon-*.png`: window and application icon at several sizes.
- `icon.ico`: Windows executable icon.
- `icon.svg`: source icon.

The editable source and the complete brand guide are in `branding/aisc/`.
